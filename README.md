# Ontub

Video platform project by GingerXYT.

**© 2026 GingerXYT. All rights reserved.**

## Vision

Ontub is planned as a real **website + mobile app + independent server**, not a single HTML page.

## Planned features

- Google, Facebook and YouTube sign-in
- User accounts, profiles and channels
- Video upload and playback
- Likes, comments and subscriptions
- Search and recommendations
- Reports and moderation
- Age-appropriate content rules

## Repository structure

```text
ontub/
├── app/       # Mobile client
├── server/    # Ontub API and backend
└── web/       # Website client
```
